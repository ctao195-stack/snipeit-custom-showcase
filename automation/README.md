# 自动化脚本

这些脚本面向 Windows 上的 Snipe-IT 运维与 Excel 报表场景。

## 目录

- `活动记录同步/`：增量同步 Snipe-IT 操作记录到 Excel。
- `Excel每日备份/`：备份工作簿并执行保留策略。
- `周度资产汇总/`：生成周度统计工作簿。
- `月度费用报告/`：生成当前月和历史月末费用清单。
- `资产生命周期看板/`：生成生命周期报表并提供查询页面。
- `公共配置/`：Python 依赖清单。

复制 `.env.example` 为本机未跟踪的 `.env`，再填写 API URL、Token 和输出路径。
所有示例值均为占位符。
