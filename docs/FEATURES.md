# 功能清单

## 已部署代码快照

### 待归还与提醒归还

- 换发新设备时可把旧设备登记为待归还，并建立新旧设备关联。
- 支持原因、预计日期、备注、修改、延期、完成和取消。
- 取消换机时保留旧设备，并归还已发出的新设备。
- “提醒归还”只承担管理提醒，资产仍归属于当前员工。
- 借用中设备可进入统一列表，列表支持状态分组、搜索、筛选与导出。
- Artisan 命令可按日期发送到期或逾期提醒。

### 设备流转和部门代管

- 单台设备直接移交给另一名员工。
- 两台已分配设备进行交换。
- 部门同事临时保管离职或待入职资产。
- 记录原使用人、保管人、地点、日期、原因、备注和原使用人状态。
- 提供代管列表、筛选、恢复和台账导出。

### 资产操作增强

- 独立退租入口与操作记录。
- 借出、归还和资产变更的企业微信富文本通知。
- 通知中的标题、资产标签和关联资产支持点击访问详情。
- 备注中的 `@资产标签` 可解析为历史关联。
- 借出和归还支持图片凭证，历史记录可查看附件。
- 管理员页面提供企业微信通知模板测试。

## 自动化工具

- Snipe-IT 活动记录增量同步到 Excel。
- 守护进程健康检查与计划任务安装脚本。
- Excel 文件每日备份与保留策略。
- 周度资产汇总报表。
- 每月最后一天生成资产费用清单。
- 按历史月末状态回溯费用清单，并排除当时已退租资产。
- 资产生命周期查询报表和轻量 Web 看板。

## 实验版本

### 分类资产编码

按资产性质与设备类型维护六个并发安全的独立序列：

- 租赁：主机、显示器、笔记本。
- 自购：主机、显示器、笔记本。

公开示例使用 `RENT-GZ-B` 和 `OWN-GZ-B`，实际前缀通过环境变量或配置文件设置。

### 企业微信通知通道

使用 Laravel Notification Channel 统一发送企业微信 Markdown 通知。该实现与线上
Observer 方案属于不同技术路线，公开仓库将它作为可评估实验保留，不能与线上方案
不经审查地同时启用。

## 明确不包含

- 已放弃的自定义功能开关。
- 真实生产配置、数据库、附件和业务数据。
- 临时排查脚本、一次性数据修复脚本和历史备份。
- 未验证的会计、折旧或完整租赁计费能力。
