# 安全说明

## 公开仓库边界

本仓库只包含脱敏代码和示例配置。以下内容永远不应提交：

- 真实 `.env`、API Token、Webhook URL、数据库与邮件密码。
- 员工、资产、费用、供应商或订单业务数据。
- 操作凭证图片、资产照片、Excel 报表和数据库备份。
- SSH 私钥、证书、日志、缓存、会话和增量状态文件。
- 生产域名、内网地址、服务器用户名和个人本机路径。

## 部署注意事项

- 企业微信机器人地址等同于发送凭据，泄露后应立即轮换。
- 图片凭证应存放在非公开目录，并通过授权控制器访问。
- 自动化 API Token 只授予读取所需数据的最小权限。
- 历史月末脚本使用数据库读取时，应使用独立只读账户。
- 生产环境保持 `APP_DEBUG=false`，错误详情只写入受限日志。

## 提交前检查

```bash
bash scripts/verify-public.sh
git diff --cached --check -- . ':!patches/*.patch'
git status --short
```

如果敏感凭据已经进入 Git 历史，仅删除最新文件并不够，必须立即吊销凭据并重写
相关历史。
