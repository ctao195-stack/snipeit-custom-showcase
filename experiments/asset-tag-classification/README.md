# 分类资产编码实验

该实验为租赁、自购与主机、显示器、笔记本的组合维护六组独立序列，并使用
数据库行锁保证并发新增资产时不产生重复编号。

公开示例前缀：

```text
RENT-GZ-B-001-00001  租赁主机
RENT-GZ-B-002-00001  租赁显示器
RENT-GZ-B-003-00001  租赁笔记本
OWN-GZ-B-001-00001   自购主机
OWN-GZ-B-002-00001   自购显示器
OWN-GZ-B-003-00001   自购笔记本
```

`overlay/` 只保存核心模型、服务、配置、迁移和测试。接入现有资产新增页面时，
还需要在控制器中校验分类、调用 `AssetTagGenerator::next()`，并在表单中增加选择项。
该功能未包含在稳定补丁中。
