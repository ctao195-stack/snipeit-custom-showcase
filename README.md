# Snipe-IT Custom Showcase

这是一个从真实 Snipe-IT 资产管理实践中整理出的公开、脱敏二开代码库。
仓库以 Snipe-IT `v8.1.18`（build `18876`）为兼容基线，展示设备归还、
设备流转、企业微信通知、操作凭证和资产报表自动化等扩展。

> 本项目不是 Snipe-IT 官方项目，也不包含任何生产数据、账号凭据或完整服务器备份。

## 功能概览

| 模块 | 能力 | 状态 |
| --- | --- | --- |
| 待归还 | 换机待归还、提醒归还、延期、完成、取消、筛选和导出 | 已部署快照 |
| 设备流转 | 单设备移交、设备交换、撤销换机 | 已部署快照 |
| 部门代管 | 原使用人、保管人、地点、原因和员工状态台账 | 已部署快照 |
| 独立退租 | 资产退租入口、状态和历史记录 | 已部署快照 |
| 企业微信 | 富文本通知、资产链接、变更详情、图片凭证 | 已部署快照 |
| 备注 @资产 | 解析资产标签并生成可点击关联 | 已部署快照 |
| 操作凭证 | 借出与归还图片上传、历史记录访问 | 已部署快照 |
| 分类资产编码 | 采购性质和设备类型六组独立序列 | 实验版本 |
| Excel 自动化 | 活动同步、周报、月度费用、历史月末和生命周期看板 | 可独立运行 |

完整说明见 [功能清单](docs/FEATURES.md) 和 [架构说明](docs/ARCHITECTURE.md)。

## 仓库结构

```text
overlay/       Snipe-IT v8.1.18 已部署二开文件覆盖层
patches/       相对官方 v8.1.18 的统一补丁
experiments/   未纳入线上稳定版的独立实验
automation/    脱敏后的 Excel 与报表自动化脚本
docs/          部署、安全、架构和文件清单
scripts/       公开前安全检查脚本
```

## 使用方式

1. 准备一个全新的 Snipe-IT `v8.1.18` 测试环境。
2. 完整备份数据库、`.env`、上传目录和现有源码。
3. 选择复制 `overlay/`，或在官方源码根目录应用 `patches/` 中的补丁。
4. 运行数据库迁移、缓存清理和针对性测试。
5. 配置队列、计划任务、Webhook 和附件存储后再进行验收。

详细步骤见 [安装与验证](docs/INSTALLATION.md)。不要把此仓库直接覆盖到生产系统。

## 安全边界

本仓库已排除真实 `.env`、API Token、Webhook、邮件和数据库密码、员工与资产数据、
附件、日志、生成报表、服务器备份和私钥。示例域名统一使用
`https://snipe-it.example.com`，示例资产前缀使用 `RENT-` 与 `OWN-`。

提交前运行：

```bash
bash scripts/verify-public.sh
```
